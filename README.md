# AOI 半自动采集工具

从高德地图网页版**半自动**采集建筑物/园区的 AOI 面边界，自动完成坐标纠偏，保存为 shp / GeoJSON / SQLite 三种格式，并内置本地 Web 控制台与地图预览管理页。

## 工作原理

1. 运行工具后自动打开本地 Web 控制台（默认 `http://127.0.0.1:9224/`）；
2. 主页点击【开始收集】→ 自动拉起一个**真实 Edge 浏览器**打开高德地图，并向页面注入采集浮窗；
3. 你在地图上正常搜索、点击任意建筑——高德会自动框出其区域边界，页面内部请求的 `detail/get/detail` 接口响应（含AOI边界 `mining_shape`）被浮窗**被动捕获**；
4. 点击浮窗【采集当前AOI】→ 坐标转换 → 保存落盘并入库。

所有网络请求均由你的真实浏览行为产生（浏览器风控 JS 自动签名），因此数据获取稳定可靠；遇到风控时工具只做原样提示，由你在弹出的浏览器中自行处理（如登录账号）。

## 功能特性

- **Web 控制台**：主页两大入口——开始收集 / 进入预览，两页面互留跳转按钮
- **多窗口采集**：可同时开多个高德收集窗口，每个窗口独立注入、互不影响
- **一键采集**：浮窗显示"已捕获"后点一下按钮即保存，无需手动导出
- **坐标纠偏**：高德 GCJ-02 火星坐标 → WGS-84(GPS)，逐点转换，精度约 0.5~2 米
- **多格式输出**：每个 AOI 输出 `shp四件套 + geojson + 简介.txt` 独立文件夹，同时写入 SQLite
- **预览管理页**：Leaflet 地图展示全部已采集面，支持关键词搜索、单个/全部上图隐藏、拖拽定位、删除（同步删磁盘+数据库）
- **详情弹窗**：预览页点击列表任意条目，居中弹出该建筑完整档案（名称、地址、中心经纬度、面范围、边界坐标串）

## 部署

```bash
# 要求: Windows + Microsoft Edge + Python 3.8+
pip install -r requirements.txt
python collectAoiTool.py
```

启动后自动打开控制台主页。本目录完全自包含（内置坐标转换算法，无外部服务依赖），整体拷贝到任意机器即可使用。

## 使用说明

| 页面 | 操作 |
|------|------|
| **控制台主页** `/` | 【开始收集】新开一个高德收集窗口；【进入预览】查看管理已采集数据 |
| **收集窗口** | 在高德地图上点击建筑 → 浮窗出现"已捕获: xxx" → 点【采集当前AOI】保存；浮窗下方有"打开预览模式"快捷链接 |
| **预览页** `/preview` | 搜索定位；条目上「上图」控制显示、「ℹ 详情」弹出完整档案、「✕」删除；支持全选显示/隐藏、拖拽条目到地图快速定位 |

## 采集结果结构

```
output/
└── 西投·云城犀谷/
    ├── 西投·云城犀谷.shp      # 多边形几何
    ├── 西投·云城犀谷.shx      # 空间索引
    ├── 西投·云城犀谷.dbf      # 属性表(NAME/ADDRESS/CITY_NAME/LONGITUDE/LATITUDE/POIID)
    ├── 西投·云城犀谷.prj      # 坐标系定义(WGS-84)
    ├── 西投·云城犀谷.geojson  # GeoJSON格式
    └── 简介.txt               # 名称/POIID/地址/点数/范围/完整边界坐标串
```

同时写入 `aoi.sqlite`（字段：名称、POIID、地址、城市、经纬度、范围、点数、坐标串、文件夹路径、采集时间）。同一 POIID 重复采集会覆盖更新。

## 注意事项

- 若浮窗提示"被风控拦截"：属正常现象，稍等几分钟再点，或在弹出的浏览器中登录高德账号可大幅提升通过率。
- 弹出的登录窗右上角可直接关闭；**不要去滑里面的滑块**（会触发短信验证码）。
- **高德源数据脏AOI现象**：个别POI在高德服务端的边界面(`mining_shape`)本身就是错位的——POI基准点正确，但关联的面图形整体偏移十几公里且形状完好。这是高德侧"点/面分离生产、批次挂接错误"导致的数据问题，经实测可稳定复现，工具无法本地修正。本工具的应对：采集时偏差>800米即在浮窗红色警告；预览页详情弹窗会显示 `⚠ 面心与基准点偏差约xxxx米` 提示，可直接删除重采或向高德反馈。
- 正常采集的数据，面心与基准点存在约 500~600 米的系统差，这是 GCJ-02→WGS-84 坐标转换的正常表现（基准点存储保留原始GCJ值），并非错误。
